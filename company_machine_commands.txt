========================================================
COMMANDS FOR SHARED COMPANY MACHINE
========================================================

1. Dataset Preparation & Splitting:
--------------------------------------------------------
# A. Extract your datasets if needed (e.g., unzip datasets/meddies_full.zip)
# B. Split the dataset into train/val/test to guarantee ZERO leakage!
python src/split_dataset.py \
    --input_file "datasets/meddies_full.jsonl" \
    --train_ratio 0.90 --val_ratio 0.05 --test_ratio 0.05 --seed 42


2. GPU Allocation Checklist:
--------------------------------------------------------
- Run `nvidia-smi` to find an empty GPU (e.g., GPU 2).
- Replace `CUDA_VISIBLE_DEVICES=X` below with your chosen GPU number.
- Replace `/path/to/your/local/qwen/model` with the absolute path to your downloaded model weights.


3. GRPO Training Command (Offline Mode):
--------------------------------------------------------
# Notice we are using the freshly created _train split!
CUDA_VISIBLE_DEVICES=X python src/train_grpo.py \
    --model_name "/path/to/your/local/qwen/model" \
    --dataset_path "datasets/meddies_full_train.jsonl" \
    --output_dir "results/grpo_defense_model" \
    --finetuning_type fft \
    --epochs 1 \
    --batch_size 2 \
    --grad_accum 4 \
    --lr 2e-5 \
    --num_generations 4 \
    --num_generations 4 \
    --limit 0  # 0 means use all available data


4. Build a Leakage-Based DPO Dataset from Meddies TRAIN Only:
--------------------------------------------------------
# Option A: survey with the local Qwen 1.5B model
CUDA_VISIBLE_DEVICES=X python -m src.survey_pii_leakage \
    --mode plain \
    --model-name "/path/to/your/local/qwen/model" \
    --local-model-label "Qwen 1.5B Local" \
    --dataset-path "datasets/meddies_full_train.jsonl" \
    --limit 0 \
    --skip-api \
    --output-file "results/survey_meddies_train_qwen.json"

# Option B: survey through the internal local API models
python -m src.survey_pii_leakage \
    --mode plain \
    --dataset-path "datasets/meddies_full_train.jsonl" \
    --limit 0 \
    --skip-local \
    --api-models gpt-oss-120b Qwen3-14B \
    --output-file "results/survey_meddies_train_api.json"

# Build DPO pairs from the local Qwen survey. Chosen responses are redacted
# with the local Meddies PII filter; rejected responses are natural summaries.
python -m src.generate_natural_dpo \
    --results_files "results/survey_meddies_train_qwen.json" \
    --model_name "Qwen 1.5B Local" \
    --dataset_path "datasets/meddies_full_train.jsonl" \
    --filter_type meddies \
    --filter_model_path "/path/to/local/vism-vi-pii-recognition" \
    --output_file "results/dpo_meddies_train_qwen.jsonl"

# For API results, use --model_name "all" or the exact result label,
# such as "GPT-OSS-120B" or "Qwen3-14B".


5. Standard DPO Command:
--------------------------------------------------------
CUDA_VISIBLE_DEVICES=X python src/train_defense.py \
    --model_name "/path/to/your/local/qwen/model" \
    --dataset_path "results/dpo_meddies_train_qwen.jsonl" \
    --output_dir "results/dpo_defense_model" \
    --epochs 3 \
    --batch_size 1 \
    --grad_accum 4 \
    --lr 5e-5


5. OGPSA Command:
--------------------------------------------------------
CUDA_VISIBLE_DEVICES=X python src/train_defense.py \
    --ogpsa \
    --model_name "/path/to/your/local/qwen/model" \
    --dataset_path "results/dpo_natural_leakage.jsonl" \
    --output_dir "results/ogpsa_defense_model" \
    --base_dataset "vlsp_summarization_capability" \
    --epochs 3 \
    --batch_size 1 \
    --grad_accum 4 \
    --lr 5e-5


6. Evaluation Command (Benchmarking):
--------------------------------------------------------
# Notice we are using the completely unseen _test split! No offset needed.

# A. Evaluate ALL models (Offline / Local Test Data)
CUDA_VISIBLE_DEVICES=X python src/evaluate_defense.py \
    --base_model "/path/to/your/local/qwen/model" \
    --dpo_model_path "results/dpo_defense_model/final" \
    --ogpsa_model_path "results/ogpsa_defense_model/final" \
    --grpo_model_path "results/grpo_defense_model/final" \
    --test_source local \
    --dataset_path "datasets/meddies_full_test.jsonl" \
    --offset 0 \
    --limit 100 \
    --methods Base_Model Pre_Filter Post_Filter Prompt_Defense DPO_Defense OGPSA_Defense GRPO_Defense \
    --output_file "results/defense_results_detailed.json"

# B. Evaluate ONLY the newly trained GRPO Model (Offline / Local Test Data)
CUDA_VISIBLE_DEVICES=X python src/evaluate_defense.py \
    --base_model "/path/to/your/local/qwen/model" \
    --grpo_model_path "results/grpo_defense_model/final" \
    --test_source local \
    --dataset_path "datasets/meddies_full_test.jsonl" \
    --offset 0 \
    --limit 100 \
    --methods GRPO_Defense \
    --output_file "results/grpo_only_results.json"

# C. Evaluate with LLM-as-a-Judge (Checks Coherence, Fluency, etc.)
# Run this AFTER running step A or B to score the generated summaries!
python src/evaluate_meddies_judge.py \
    --results_file "results/grpo_only_results.json" \
    --provider "local" \
    --model "gpt-oss-120b" \
    --limit 50


7. Privacy Filter (One-shot Defense Baseline):
--------------------------------------------------------
# A. OpenAI Privacy Filter (Requires pre-downloaded cache)
CUDA_VISIBLE_DEVICES=X python src/openai_privacy_filter.py

# B. Meddies PII v2 Filter (Fully offline via local path)
CUDA_VISIBLE_DEVICES=X python src/meddies_privacy_filter.py \
    --model-path "/path/to/your/local/meddies-pii-v2/model"
